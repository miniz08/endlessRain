# 用户综合行为评级功能运行机制文档

## 评级计算流程

1. 用户发布文章后，AI 服务生成文章评分。
2. AI 服务将评分和审核状态写入数据库。
3. 用户服务查询用户所有文章的 AI 均分和审核状态分布。
4. 用户服务查询这些文章获得的推荐事件反馈。
5. 系统计算内容质量分、合规分和互动反馈分。
6. 系统按权重生成综合分和等级。

## 分数构成

综合分由三部分组成：

- 内容质量分：来自专业度、友好度、理性度和合法性。
- 合规分：由低优先级、复核、拒绝和举报等信号扣分。
- 互动反馈分：由点赞、评论、收藏、关注作者、阅读完成等正向反馈加分，由隐藏和举报扣分。

## 等级划分

| 等级 | 分数区间 |
| --- | --- |
| A | 85 分及以上 |
| B | 70-84 分 |
| C | 50-69 分 |
| D | 50 分以下 |

## 风险信号

系统会生成可解释的风险信号，例如“低优先级内容 1 篇”“收到举报 2 次”“内容合法性均分偏低”。这些信号用于辅助用户理解评分来源，也可作为后续管理后台筛查依据。

## 与其他模块协作

- AI 内容评级模块提供内容质量分。
- 推荐模块提供互动反馈事件。
- 内容管理模块提供审核状态。
- 用户主页前端展示最终评级。
